# Приймання CRM 1.0 у погодженому обсязі

Для поточної версії застосовується [перелік 1.0](V1_DEPLOYMENT.md). Google-вхід і перевірка з телефона залишаються ручними до дозволу на ресурси. Drive, Calendar, Gmail, ШІ, фінанси та імпорт виключені з цього випуску за дорученням власника; нижче збережено загальний перелік майбутніх етапів.

# Перелік приймальних випробувань

Тестувати лише на вигаданих клієнтах та грантах.

- [ ] Після входу відкривається «Реєстр грантових заявок»; у локальному М1 — після відкриття кореневої сторінки без входу.
- [ ] Пошук, клієнт і статус комбінуються; сортування працює в обох напрямках, групування не губить записи; порожній результат має пояснення.
- [ ] Жовті/сірі/незабарвлені рядки відповідають статусам, статус є текстом; кожне посилання веде до правильного досьє.
- [ ] На 360 px лише таблиця має горизонтальне прокручування; керування доступне клавіатурою.
- [ ] Наступні етапи: ручне збереження, оновлення Sheets та повторний Excel/CSV-імпорт не створюють дублів і не втрачають дані при конфліктах/збоях. У М1 ці дії недоступні.

- [ ] Вхід під особистим Google-акаунтом власника працює з комп'ютера і телефону.
- [ ] Сторонній Google-акаунт НЕ відкриває CRM і НЕ бачить даних.
- [ ] Файли, календар і таблиця приватні, сторонніх спільних доступів немає.
- [ ] Створити ГО, БФ, фізособу, компанію; змінити, знайти, заархівувати, відновити кожну картку.
- [ ] Кілька контактів прикріплюються до одного клієнта, зберігається журнал взаємодій.
- [ ] Досьє має окремі поля для організації та фізособи.
- [ ] Документи підв'язуються через Drive ID; зміна назви папки не розриває зв'язок.
- [ ] Створення гранту з дедлайном, країною, видами заявників, офіційним URL; дублікати визначаються.
- [ ] Правила грантового добору працюють **без ШІ**, відображають причини відповідності.
- [ ] Один грант зв'язується з кількома клієнтами, одна організація має кілька заявок.
- [ ] Завдання з календарною датою створює **одну** подію в окремому CRM-календарі.
- [ ] Повторний запуск синхронізації не створює другу подію.
- [ ] Зміна дати оновлює ту саму подію; скасування не зачіпає інші календарі.
- [ ] Нагадування приходить у Google Calendar на телефон (перевірити налаштування сповіщень).
- [ ] Мобільний інтерфейс працює на ширині 360 px без горизонтального скролу.
- [ ] Усі суми й дати відображаються коректно, без втрати часових поясів.
- [ ] Послуги/договори/оплати обліковуються й зв'язані з клієнтом.
- [ ] Дані експортуються в CSV/JSON, створюється резервна копія та успішно відновлюється на тестовій базі.
- [ ] Помилки Google/мережі не спричиняють дублювання або втрату даних.
- [ ] Жодного платного компонента; жодних секретів чи реальних даних клієнтів у GitHub.
- [ ] Без налаштування ШІ вся основна функціональність залишається робочою.
