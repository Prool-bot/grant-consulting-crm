# Перше завдання для Codex — скопіювати повністю

Ти — технічний виконавець проєкту «Каталог клієнтів — Грантовий консалтинг». Працюй **у цьому публічному GitHub-репозиторії**.

Перед початком прочитай `README.md`, `AGENTS.md` і всі файли в `docs/`. Врахуй, що призначення системи — персональна безкоштовна CRM для фрилансера з грантового консалтингу в Україні, з українськомовним адаптивним інтерфейсом. Майбутнє розгортання — лише в особистому Google-акаунті власника (адреса не повинна потрапляти до GitHub), але **поки НЕ підключайся до Google і НЕ створюй реальних ресурсів**.

**Поточне завдання — М1: архітектура та локальний каркас без доступу до Google.**

1. Запропонуй чітку структуру коду для Google Apps Script (`.gs`, HTML/CSS/JS), тестів і конфігурації `clasp`, без секретів.
2. Реалізуй мінімальний україномовний адаптивний прототип вебінтерфейсу: робочий стіл, список клієнтів, порожня картка клієнта, завдання, гранти. Лише вигадані приклади, без реальних даних.
3. Підготуй адаптери сховища і календаря з абстракціями, щоб тести працювали без Google API. **Не вмикай** реальні інтеграції на цьому кроці.
4. Додай тести валідації полів, генерації UUID, пошуку/фільтрів, а також базових бізнес-правил статусів.
5. Підготуй README для запуску локальних тестів і опиши, як у наступному кроці підключити Google Apps Script через `clasp`, не публікуючи токенів.
6. Перевір, що немає жодного платного компонента, зайвих зовнішніх бібліотек і облікових даних.
7. Після завершення подай короткий звіт українською: створені файли, виконані перевірки, відкриті ризики, що потрібно від власника (максимум мінімальних дозволів).

Не реалізовуй наступні етапи без узгодження. Працюй окремою гілкою і запропонуй Pull Request замість прямого переписування основної гілки.
