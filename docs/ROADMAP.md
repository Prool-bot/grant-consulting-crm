# Дорожня карта та контрольні точки

## М0. Узгодження проєкту та публічний репозиторій
- [ ] Публічний GitHub-репозиторій `Prool-bot/grant-consulting-crm` створено.
- [ ] Додано документацію, `AGENTS.md`, `.gitignore`.
- [ ] Codex має доступ до репозиторію з правом запропонувати зміни через PR.
- [ ] Жодних клієнтських або облікових даних у репозиторії.

## М1. Каркас і структура даних
- [x] Головний екран — демонстраційний реєстр заявок: пошук, клієнти, статуси, сортування, групування, кольори рядків і посилання на досьє.
- [x] Організована структура source/tests/docs, локальні перевірки, єдині стилі інтерфейсу.
- [ ] Ініціалізація аркушів на тестових даних; заповнення без дублів при повторному запуску.
- [ ] Вебкабінет працює лише для власника; безпечне повідомлення про відмову в доступі.

Локальна частина М1: див. `M1_LOCAL.md`. Ініціалізацію без дублів перевірено на адаптері в пам’яті; реальні аркуші та авторизація власника очікують окремого дозволу. Серверний вхід поки завжди відмовляє в доступі.

## М3. Гранти, заявки та календар
- [ ] Ручне введення та збереження заявок; після входу власника відкривати реєстр.
- [ ] Автоматичне оновлення з погодженої Google Sheets: стабільні ключі, конфлікти, повтори після збоїв, журнал синхронізації.
- [ ] Імпорт Excel/CSV з попереднім переглядом, перевіркою даних і зв’язків, захистом від повторів. Без платних залежностей; вибір Excel-парсера та ліцензію перевірити перед додаванням.
- [ ] Тести повторного імпорту, змінених рядків, однакових назв різних клієнтів, конфліктів і часткових помилок без втрати даних.
- [ ] Гранти, заявки, зв'язки клієнт ↔ грант.
- [ ] Правила підбору без ШІ, причини відбору.
- [ ] Окремий Google Calendar, створення/зміна/скасування завдань і дедлайнів без дублів.
- [ ] Тестові сповіщення на телефоні, приватність назв подій.

## Принцип роботи Codex
Одна контрольна точка = одна або кілька невеликих PR. Спочатку план, потім код, тести, короткий звіт, скриншоти інтерфейсу (на синтетичних даних), потім затвердження. Без автоматичного розгортання у реальний Google-акаунт.
