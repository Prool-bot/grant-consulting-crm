# Каталог клієнтів — Грантовий консалтинг

Персональна безкоштовна CRM для супроводу ГО, благодійних фондів, компаній, ФОП та фізичних осіб у грантовій діяльності.

**Стан:** реалізовано локальний прототип М1 на вигаданих даних; Google не підключений, застосунок не розгорнутий. М2 не розпочато.

## Локальний запуск М1

Головна сторінка — **Реєстр грантових заявок**: демонстраційна таблиця з пошуком, фільтрами, сортуванням, групуванням за клієнтами та переходами в досьє. Жовті рядки — подано/очікується рішення, сірі — відхилено, незабарвлені — у роботі. Збереження, Sheets та Excel/CSV-імпорт заплановані на наступні етапи.

Потрібен Node.js 22+. Без встановлення залежностей: `npm test`, `npm run build`, `npm start`. Відкрити `http://127.0.0.1:4173`; зупинка — Ctrl+C.

Структура, межі прототипу та майбутня підготовка clasp: [`docs/M1_LOCAL.md`](docs/M1_LOCAL.md). Форми не зберігають дані; не вводьте справжні клієнтські дані.

## Автоматичні перевірки Pull Request

GitHub Actions запускає `npm test` і `npm run build` на Node.js 22 під час створення, оновлення комітів або повторного відкриття кожного Pull Request. Налаштування: [`.github/workflows/ci.yml`](.github/workflows/ci.yml). Локально перед передачею змін виконайте ті самі дві команди.

Залежності встановлювати не потрібно. Використано стандартний Linux runner, безкоштовний для публічних репозиторіїв, та офіційні GitHub Actions із зафіксованими SHA. Перевірки мають лише право читання коду, не потребують секретів, Google OAuth або ШІ та нічого не розгортають. Застарілий запуск скасовується після нових комітів у тому самому PR; ліміт виконання — 10 хвилин. Це перевірки локального М1; М2 не розпочато.

## Межі проєкту
- **Власник даних:** окремий особистий Google-акаунт власника (не використовувати акаунти організацій; фактичну адресу не публікувати в GitHub).
- **Платформа:** Google Apps Script (вебзастосунок), Google Sheets (дані), Google Drive (документи), Google Calendar (події й нагадування); Gmail — окрема, контрольована інтеграція.
- **Вартість:** жодних обов'язкових платних тарифів і платних розширень; усі безкоштовні сервіси мають квоти й можуть змінювати їх.
- **Інтерфейс:** українська, зручний з комп'ютера і телефона.
- **ШІ:** факультативний, вимкнений за замовчуванням, лише на вимогу користувача і в межах явних бюджетів. Базова CRM працює без нього.
- **Безпека:** **публічний** GitHub-репозиторій **виключно для коду, документації та синтетичних тестових даних**. Жодних клієнтських даних, ключів, документів та OAuth-токенів.

## Важливі правила
- Не запускати масових розсилок і не надсилати повідомлень без окремого явного підтвердження користувача.
- Синхронізація з Google Calendar у першій версії **одностороння (CRM → календар)** з оновленням / скасуванням подій і захистом від дублів. Двостороння синхронізація — окремий майбутній етап.
- Не надсилати конфіденційні дані клієнтів сторонньому ШІ без явної згоди.
- Не змінювати налаштування Google-акаунтів та існуючі календарі / файли; створювати окремі робочі ресурси тільки після підтвердження.

Стан реалізації відстежується за `docs/ROADMAP.md`.
